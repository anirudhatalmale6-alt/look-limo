The same steps, in writing

  1. Open your files on GitHub — each page of the site is a .html file (index.html is the home page).
  2. Click a page, then click the pencil (Edit) icon near the top-right of the file.
  3. Change the wording, scroll down and click the green Commit changes button to save.
  4. To swap a photo or the hero video, open the assets folder and upload your file using the same filename (e.g. logo.jpg, hero-video.mp4).
  5. GitHub republishes the site automatically — refresh in about a minute and your change is live.
